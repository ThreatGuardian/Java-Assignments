🏆 Java Programs Archive: Academic Projects & Management Systems

A curated portfolio demonstrating progressive mastery of Core Java, Object-Oriented Programming, and practical system development.

💡 Overview

This repository archives a collection of academic projects developed in Java. The focus is on implementing Management Systems across various domains (e.g., Library, Inventory, Employee) using Object-Oriented Design (OOD) principles and practical enterprise concepts. Each folder represents a distinct project, showcasing progressive complexity, from basic console applications to systems involving database connectivity and multi-threading.

✨ Key Demos & Technical Highlights

Each program is a structured solution that demonstrates proficiency in several core and advanced Java concepts:

Core & OOD Principles

Object-Oriented Programming (OOP): Thorough use of Classes, Inheritance, Polymorphism, and Encapsulation for modular and maintainable code.

Data Structures: Effective use of standard Java Collections for data handling and management logic.

Error Handling: Robust implementation of Exception Handling using try-catch-finally blocks for reliable application flow.

Advanced Concepts & Real-World Simulation

Database Connectivity (JDBC): Projects in Java 9 and Java 10 demonstrate connection, CRUD (Create, Read, Update, Delete) operations, and secure interaction with external SQL databases (e.g., Oracle/JDBC).

Multi-threading: Projects like Java 6 showcase the use of Threads and Runnables for concurrent operations (e.g., a ticket booking system).

File I/O: Demonstrations of reading from and writing to files for persistence, including projects involving file stream processing (Java 7).

Networking & RMI: Projects in Java 11 (Socket Programming) and Java 12 (Remote Method Invocation) illustrate client-server architecture and distributed computing principles.

🛠 How to Run

Clone the repository:

git clone [https://github.com/ThreatGuardian/Java-Assignments.git](https://github.com/ThreatGuardian/Java-Assignments.git)
cd Java-Assignments


Compile: Navigate into the desired project directory (e.g., Java 1/) and compile the .java files using the Java Development Kit (JDK).

javac YourMainClass.java


Run: Execute the compiled class file.

java YourMainClass


Note: For projects involving external dependencies (e.g., Java 9 or Java 10 requiring JDBC drivers like ojdbc8.jar), ensure the required JAR files are included in your classpath during compilation and execution.
